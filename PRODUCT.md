# Jarvis Control

## Product

Jarvis is a private operator system for one owner managing personal commitments, an AI-automation agency, client scopes, and bounded agents. It is an instrument for deciding, delegating, reviewing, and remembering—not a generic analytics dashboard.

## Primary user

The owner operates mainly from a desktop, wants a fast conversational command surface, and needs mobile steering through Telegram later. They must understand what needs attention, what is running, which authority and memory an agent received, and what can be safely approved or stopped.

## Platform

Web product UI. Local loopback is the trusted V1 surface. Remote access and provider connections require separate security gates.

## Jobs

1. Ask Jarvis for a grounded answer and open its evidence.
2. See today's calendar, focus, reviews, and approval queue.
3. Traverse human → personal/agency → company/client/project → agent containment.
4. Inspect delegation, grants, memory sleeves, runs, artifacts, elapsed time, token usage, and known-cost coverage.
5. Build reviewed pages and reusable agent blueprints without introducing executable UI or self-authorizing agents.

## Trust promises

- Personal, agency, and client memory never blend implicitly.
- Containment grants no authority; tool and sleeve access are explicit edges.
- External or irreversible actions remain approval-gated.
- The interface shows evidence and structured traces, never hidden reasoning.
- Unknown cost, stale data, unavailable sources, and planned capabilities are labeled honestly.
